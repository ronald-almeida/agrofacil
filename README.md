# Checkout AgroFácil

Checkout PIX hospedado na Vercel com integração server-side à Black Cat. A API key fica na variável sensível `BLACKCAT_API_KEY` em Production.

O pedido padrão custa R$ 197,70 (preço de referência R$ 497,00; desconto de 60,22%). A opção de acesso vitalício adiciona R$ 67,00. Nenhum banco de dados próprio é usado para armazenar cobranças.
